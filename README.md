# ザブングル家の献立（PWA）

曜日・季節・在庫・メルママの好みから献立を提案し、クックパッド / クラシル / Nadia の検索結果を開くアプリ。
気に入ったレシピは「レシピ帳」に登録して育てていく。

## ファイル構成

| ファイル | 役割 |
|---|---|
| `index.html` | 画面 |
| `style.css` | 見た目 |
| `app.js` | 提案ロジック・レシピ帳・履歴・設定 |
| `data.js` | 献立候補リスト（ここを編集すると候補を増やせる） |
| `manifest.json` / `sw.js` | PWA（ホーム画面追加・オフライン対応）用 |
| `icons/` | アプリアイコン |

## 提案ルール（app.js `scoreDish`）

- 日・水：魚を優先（翌日が燃えるゴミの日）。それ以外の日は魚の主菜を少し下げる
- 月・火：ヘルシーな料理を優先
- 金・土：お酒に合う料理を優先
- 旬の食材、在庫食材、メルママの好物、食物繊維、大豆製品を加点
- 直近7日間に食べた料理・前日と同じ分類（肉/魚など）は減点
- 牛肉は赤身のみ、そば・生魚は候補に入れていない

## PCで動作確認する

このフォルダで以下を実行し、ブラウザで http://localhost:8000 を開く。
（ローカルにWebサーバーを立てるコマンド。`Ctrl + C` で停止）

```
npx serve -l 8000
```

## GitHub Pagesで公開する（iPhoneで使うため）

1. GitHubで新しいリポジトリを作成（例: `kondate`）
2. このフォルダのファイル一式をアップロード（`CLAUDE.md` は含めなくてもよい）
3. リポジトリの **Settings → Pages** で、Branch を `main`、フォルダを `/ (root)` にして Save
4. 数分後に `https://<ユーザー名>.github.io/kondate/` で公開される

> ⚠️ GitHub Pagesは誰でも閲覧できる公開ページになる。コードに個人情報は含めていないが、
> `CLAUDE.md`（家族の情報を含む）はアップロードしないのがおすすめ。
> レシピ帳・履歴はiPhone内にだけ保存されるので公開されない。

## iPhoneのホーム画面に追加する

1. iPhoneの **Safari** で公開URLを開く
2. 共有ボタン（□に↑）→ **ホーム画面に追加**
3. ホーム画面の「献立」アイコンから起動

## 注意

- データ（レシピ帳・履歴・設定）はiPhone内に保存される。Safariで開いたときとホーム画面アプリでは保存場所が別。
- 機種変更に備えて、設定タブの「書き出し」でときどきバックアップを取る。
- アプリを更新したのに古い表示のままのときは、アプリを一度完全に終了して開き直す。
